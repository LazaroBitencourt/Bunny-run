# Bunny Run 2D

Jogo 2D endless runner feito em **Unity** com **C#**.  
Controle um coelho, pule os obstáculos e tente bater o recorde.

**Desenvolvedor:** [Lázaro Bitencourt](https://github.com/LazaroBitencourt)

---

## Como jogar

- O coelho corre sozinho
- **Espaço** ou **clique** para pular
- Desvie de cactos, pedras, pássaros e outros obstáculos
- A velocidade aumenta com o tempo
- Ao colidir: Game Over → clique em **Retry** para jogar de novo

---

## Tecnologias

- Unity 2D
- C#
- Pixel art (sprites próprios)
- Parallax no cenário
- Áudio (música + efeitos)
- Recorde salvo com PlayerPrefs

---

## Scripts principais

| Script | Função |
|--------|--------|
| GameManager | Controla o jogo, velocidade, game over e recorde |
| Player | Pulo, gravidade e colisão |
| Obstacle | Movimento e destruição dos obstáculos |
| ParallaxBackground | Movimento das camadas de fundo |
| AudioManager | Música e sons |
| AnimatedSprite | Animação dos sprites |

---

## Como abrir

1. Clone o repositório
2. Abra no Unity Hub
3. Abra a cena principal
4. Pressione **Play**
5. Ou baixe o arquivo zip do jogo.
